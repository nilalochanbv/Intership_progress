# Day 3 – API Development & Testing

## Overview
This folder contains practical exercises completed during Day 3 of the AI & Python internship pre-warmup.

## Tasks Completed

### T11 – HTTP & REST Concepts
- Learned HTTP methods: GET, POST, PUT and DELETE.
- Understood API requests and responses.
- Explored HTTP status codes.

### T12 – Calling APIs with Python Requests
- Used Python Requests to call REST APIs.
- Retrieved user information from JSONPlaceholder.
- Processed API responses.

### T13 – JSON Responses & API Authentication
- Parsed JSON responses.
- Practiced sending API keys through HTTP headers.
- Tested requests using HTTPBin.

### T14 – Building an API with FastAPI
- Created a Student Management API.
- Implemented GET and POST endpoints.
- Explored automatic API documentation using Swagger UI.

### T15 – API Testing
- Tested GET and POST endpoints.
- Used PowerShell Invoke-RestMethod.
- Verified API responses and student records.
